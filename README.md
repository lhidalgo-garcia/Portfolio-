# Welcome to My Portfolio

This portfolio showcases academic and applied projects focused on data analysis, business decision-making, and geospatial analysis through Management Information Systems coursework.


## Projects

### GIS Project: Frozen Yogurt Location Analysis (Group Project)
- Conducted GIS-based analysis to evaluate optimal business locations for a frozen yogurt franchise using mapping tools and competitor data. Identified underserved markets in Santa Ana, Newport Beach, and Costa Mesa by comparing demand and competition levels relative to Irvine. Evaluated geographic accessibility, market saturation, and demographic indicators to support data-driven location recommendations. Developed and presented findings through an interactive StoryMap visualization tool.
